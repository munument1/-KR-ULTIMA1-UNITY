[설치 방법]
1. 최신 Ultima I Unity를 깨끗한 상태로 준비합니다.
2. 이 압축 파일의 내용을 'Ultima I Unity.exe'가 있는 폴더에 풉니다.
3. Install_Korean_Patch.bat를 실행합니다.
4. 원본 해시를 확인한 뒤 자동으로 한국어 패치를 적용합니다.

※ Python 설치는 필요하지 않습니다. Windows PowerShell을 사용합니다.
※ v0.3은 최신 게임 DLL과 호환되지 않습니다. 최신 빌드에는 v0.4를 사용하세요.
※ 기존 v0.3 패치 파일이 남아 있다면 최신 원본 게임으로 다시 설치/업데이트한 뒤 적용하는 것을 권장합니다.
※ v0.4 백업은 .u1k-original-v0.4 확장자로 생성됩니다.
