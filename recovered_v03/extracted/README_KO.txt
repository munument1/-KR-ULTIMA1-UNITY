Ultima I Unity 한국어 패치 v0.3

설치 방법
1. Ultima I Unity가 설치된 폴더를 엽니다.
2. 이 압축의 파일을 모두 `Ultima I Unity.exe`가 있는 폴더에 압축 해제합니다.
3. 같은 폴더에서 `Install_Korean_Patch.bat`를 실행합니다. 별도의 경로 입력은 필요 없습니다.
4. 원본 파일 해시가 맞으면 자동으로 백업 후 한국어 패치를 적용합니다.

현재 상태
- 한국어 UI/대사/상점 데이터 적용
- Galmuri11 기반 한글 폰트 적용
- HUD `Hits`는 `체력`으로 수정
- 메인 화면 문구 겹침 수정
- 도시의 상점 간판 그래픽(TRANSPORT/MAGIC/PUB/ARMOUR/WEAP/FOOD)은 현재 영문 유지
- 테스트 버전이므로 오역/잘림/미번역 제보 환영

주의
- 패치 데이터만 포함하며 원본 게임 실행 파일/전체 게임 리소스는 포함하지 않습니다.
- 현재 제작에 사용한 Ultima I Unity 빌드와 파일 해시가 다르면 설치를 중단합니다.
- 원본 백업은 `.u1k-original` 확장자로 자동 생성됩니다.
